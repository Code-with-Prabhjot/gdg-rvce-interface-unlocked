# Design Note — GDG on Campus RV College of Engineering (Interface Unlocked)

### 1. Visual Direction & Community Fit
To represent **GDG on Campus RV College of Engineering (`GDG RVCE`)**, we rejected generic corporate templates and superficial glassmorphism in favour of an **Architectural Blueprint & Kinetic Canvas**. Grounded in Swiss drafting systems—strict 8-pixel rhythms, clear typographic hierarchy, and clean hairline geometry—every module frames student software craft like a real engineering release. Campus coordinates (`12.9237° N, 77.4987° E`), four interactive Bento simulators, an HTML5 constellation network, a hardware-accelerated Three.js 3D chevron prism (`THREE.Timer`), and built-in developer diagnostics (`ApiInspectorModal`, `Shift+X` Blueprint X-Ray, CLI terminal) reward exploration without visual clutter. Across Grid, Schedule List, Calendar Matrix, and Chapter Topology views, technical telemetry stays calm, purposeful, and immediately legible.

### 2. Colour & Typography System
Our palette enforces strict semantic mapping across Google's four official colours paired with verified high-contrast accessible ink tokens (`#1D4ED8`, `#C5221F`/`#A50E0E`, `#15803D`, and `#FBBC04` paired with `#111827` dark ink) so solid actions, category pills, and true 4-stop CSS gradients exceed WCAG AA `4.5:1`–`10:1` contrast across both **Daylight Blueprint** (light drafting grid) and **Obsidian IDE** (`#0A0D12` dark canvas) themes with native `color-scheme` support:
- **Google Blue (`#4285F4`):** Core workshops, systems labs, and active navigation states.
- **Google Red (`#EA4335`):** Flagship buildathons, sprint badges, and urgent countdowns.
- **Google Yellow (`#FBBC04`):** Study jams, community keynotes, and design systems, strictly paired with `#111827` dark ink or high-contrast `--accent-yellow-text` tokens for light surfaces.
- **Google Green (`#34A853`):** Open-source builds, CI/CD telemetry, verified passes, and API `200 OK` indicators.

Typography pairs **Space Grotesk** for architectural display headings, **Plus Jakarta Sans** for neutral UI copy, and **JetBrains Mono** for code specs and status readouts.

### 3. Brand Guidelines, Security & Challenge Compliance
Every detail strictly obeys Interface Unlocked rules and Google community policies. The separated 4-colour `< >` chevron mark preserves clear breathing room across 51 self-contained SVGs, multi-resolution favicons, and `1200×630` OpenGraph cards. Chapter naming stays consistently **"GDG on Campus RV College of Engineering"** or **"GDG RVCE"**, backed by the global footer independence disclaimer. All events, speakers, and builders use purely fictional sample data across the 3 user-facing routes (`/`, `/events`, `/team`) and 5 stateless Next.js 15 Route Handlers (`/api/*`), with HTTP security headers, keyboard-first 44×44px mobile targets, zero horizontal overflow (`320px–2560px`), and zero analytics, RSVP counters, attendee tallies, or live chat.
